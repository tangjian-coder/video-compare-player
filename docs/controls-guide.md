# 界面控件说明

窗口自上而下：**左右视频块 → 主时间轴 → 共享传输栏 → 状态栏**。

主题：macOS 深色模式色板（系统蓝 `#0A84FF` / 系统绿 `#30D158` / 靛蓝 `#5E5CE6` / 苹果橙缩放读数 / 苹果黄同步锚点）；A 块徽章蓝色、B 块徽章绿色，应用图标见 `assets\icon.ico`。

## 视频块（左 A / 右 B，各一套）

| 控件 | 作用 |
| :--- | :--- |
| `A` / `B` 徽章 | 块的标识，蓝色标签 |
| 文件名 | 当前加载的视频文件名 |
| 视频区 | 渲染画面。**滚轮**＝**两侧同时**按档位缩放（各自在自己档位上前进/后退一档，保留倍率差）；**按住左键拖拽**＝**两侧同时**平移（像素级 1:1 跟随鼠标，各自边缘钳制）；**双击**＝**两侧同时**复位缩放、平移和旋转 |
| **Ctrl+滚轮** | 仅本侧缩放 |
| **Ctrl+左键拖拽** | 仅本侧平移（1:1 抓取，拖到边缘自动停住） |
| **Ctrl+双击** | 仅本侧复位缩放、平移和旋转 |
| `<` / `>`（块底部） | **本侧单独**逐帧后退/前进。用于把各自画面定位到同一物理瞬间（如秒表跳到同一读数） |
| `Play` / `Pause`（块底部） | **本侧单独**播放/暂停——快速跳到同步点附近再配合 `<` `>` 微调；同步播放中按它会先全局暂停再单独控制该侧 |
| `↻ 90°`（Play 旁） | **本侧顺时针旋转 90°**（循环 0→90→180→270→0），旋转时平移自动回中、缩放保留，当前角度直接显示在按钮上 |
| `×2.4`（块底部） | 本侧当前缩放档位，琥珀色，始终显示（1x 显示 `×1.0`）。缩放/平移默认操作**两侧**，Ctrl 修饰后仅操作**本侧** |
| 时间读数 | 该视频自己的时间轴位置（秒），等宽字体显示 |

## 主时间轴（共享传输栏上方）

双杆滑杆（上＝A，下＝B），共享同一时间比例尺（满量程＝两个视频中较长的那个），因此播放时**两个白色旋钮移动速度严格一致**，水平间隔恒等于同步偏移：

- 蓝色段＝已播放部分；灰色段＝该视频剩余部分；**暗色尾段＝超出该视频时长的死区**（短视频那根杆的尾部，直观显示时长差异）
- 顶部无字刻度线＝秒刻度（自适应间距）
- **黄色菱形**＝同步锚点：两根杆**各有一个**，对齐后错开显示（A 的锚点在 A 杆的 point_a 处、B 的在 B 杆的 point_b 处）——两锚点的水平距离就是 offset，diff 一目了然；未同步时无锚点
- **点击或拖动任意一根杆**＝两侧同步精确跳转（保持对齐）；拖动中做快速预览（按关键帧），**松手瞬间精确落点**
- 未加载的那侧显示为整条死区轨道

## 共享传输栏（居中三组）

左组（文件）：

| 控件 | 作用 |
| :--- | :--- |
| `Open A` / `Open B` | 弹文件对话框，为左/右块选择视频（也可直接拖文件进块） |

中组（走带控制）：

| 控件 | 作用 |
| :--- | :--- |
| `\|<` | 跳到对齐区间的**第一帧** |
| `<` / `>` | **两侧同步**逐帧后退/前进（步长以 A 的帧率为准） |
| `Play` / `Pause` | 同步播放/暂停；播到结尾后再按会回到开头重播 |
| `>\|` | 跳到对齐区间的**最后一帧** |

右组（速度与同步）：

| 控件 | 作用 |
| :--- | :--- |
| `speed` 下拉框 | 播放速度：0.1x / 0.25x / 0.5x / 1x / 2x / 4x，两侧同时生效 |
| `⇄ Align current frames` | **一键同步**：把两侧"当前帧"设为同步锚点（等同 `S` 键） |
| `● not synced / +x.xxxs` | 同步状态指示：琥珀色＝未同步，绿色＋偏移量＝已同步 |
| `Clear sync` | 清除同步点，时间轴恢复原始对齐（offset = 0） |
| `⏺ Rec` | **录屏**开始/停止（等同 `F9`），见下节 |
| `✛` | **十字准星**开关（等同 `C`）：两侧**窗格中心**各显示一条 **1px 红色十字线**（mpv OSD 渲染）。缩放/平移/旋转时十字**保持不动**——是屏幕参照物，正好用来对比两侧运动幅度；状态会记入设置，开启时也会被录进录屏 |

## 录屏（F9）

把**两块视频区**（含标题栏与本侧控制条，不含时间轴/走带栏/状态栏）录成 mp4，用于对齐后同步播放的对比展示：

- **`F9` 或 `⏺ Rec`** 开始：按钮变红并显示计时 `⏺ 0:12`；再按一次停止
- 停止后自动在资源管理器中定位到产物文件，保存位置：`视频\vcplayer\compare_年月日_时分秒.mp4`
- 编码按机器能力自动选档（启动时探测一次）：**桌面复制 + NVENC 硬编 60fps**（N 卡）→ **桌面复制 + x264 30fps**（任意显卡）→ **gdigrab + x264**（仅完整版 ffmpeg；远程桌面等 DDA 不可用场景）
- **主屏录制**所有配置可用；窗口在副屏时需要 gdigrab 档（打包版 ffmpeg 不含 gdigrab，会提示把窗口移回主屏）
- **录制期间不要移动/缩放窗口**（录的是屏幕区域），也不要让其他窗口遮挡视频区；鼠标指针会被录进去

## 同步用法（一步完成）

两个视频拍摄开始时间不同是正常情况，同步锚点就是为此设计的：

1. 用各块底部的 `Play` 单侧播放快速到达目标段，`<` `>` 逐帧走到**同一物理瞬间**——比如秒表刚跳到 `05.00` 的那一帧（选数字跳变帧，别选读数静止的中间帧）
2. 点 **`⇄ Align current frames`**（或按 `S`）
3. 完成：状态 chip 变绿显示 offset，两根杆各出现一个黄色菱形锚点，之后所有播放/逐帧/拖动都按对齐时间走

同步后再按 `Space` 同步播放时，若两侧偏差超过约一帧（如手动步进过 B），会先把 B 精确吸附到 A 当前对齐位置再起播；偏差在一帧内则直接起播，由速度微调环收敛残余偏差（避免无谓的 seek 卡顿）。

两台设备帧率不同时（如 120fps vs 30fps），以高帧率侧的跳变帧为准，低帧率侧选"刚跳到新读数的第一帧"，残余误差最多一帧。换视频后旧同步自动清除，需重新对齐。

## 状态栏（窗口最底部）

`A 12.345s | offset +0.040s | drift +0.0ms | 120fps`

| 字段 | 含义 |
| :--- | :--- |
| `A ...s` | 主时间轴当前位置（即 A 的时间） |
| `offset` | 同步偏移量：B 相对 A 的时间差 |
| `drift` | 播放中两侧的实时偏差。播放时通过**微调 B 的播放速度（±10% 内）**连续收敛，启动瞬间约几十毫秒的管线唤醒差会在 ~1 秒内平滑归零；暂停时自动吸附到 ≤1 帧 |
| `fps` | 参考帧率（A 视频的帧率，也是逐帧步进的步长基准） |

## 快捷键

| 键 | 功能 |
| :--- | :--- |
| `Space` | 同步播放/暂停 |
| `←` / `→` | 双侧同步逐帧后退/前进 |
| `↑` / `↓` | 变速（在速度档位间循环） |
| `Home` / `End` | 跳到对齐区间开头/结尾 |
| `S` | **一键对齐当前帧**（等同 `⇄ Align current frames`） |
| `R` | 清除同步（等同 `Clear sync`） |
| `F9` | **录屏**开始/停止（等同 `⏺ Rec`） |
| `C` | **十字准星**开关（等同 `✛`） |
| `Ctrl+O` | 为当前块打开视频文件 |
