# 界面控件说明

窗口自上而下：**视频块区（2–4 块，可自由排列）→ 主时间轴 → 共享传输栏 → 状态栏**。

主题：macOS 深色模式色板（系统蓝 `#0A84FF` / 系统绿 `#30D158` / 靛蓝 `#5E5CE6` / 苹果橙 `#FF9F0A` / 苹果黄同步锚点）；**A 块徽章蓝色、B 块绿色、C 块靛蓝、D 块橙色**，应用图标见 `assets\icon.ico`。

## 视图管理（＋ / － / V 键）

默认 **2 视图**（A、B）。`＋` 按钮（或 `V` 键）追加一个视图（C、D，**上限 4 个**）；`－` 按钮移除**最后**一个视图（A、B 永不移除，只允许从末尾减）。追加/移除即时生效：

- 新视图带自己的播放器与控制条，拖文件或 `Open C` / `Open D` 加载视频；未加载时时间轴显示为死区轨道
- 视图数变化后按当前排列重排；时间轴轨道随视图数增减
- **录屏期间禁用**增删视图与拖动排列（避免录进布局变化）
- 性能提示：每视图一个 mpv 实例。10-bit H.264 等硬解不支持的格式走 CPU 软解，4 视图同播可能吃满解码余量，帧率异常时减到 3 视图或换硬解格式

## 窗格排列（拖动标题栏）

2 视图默认并排，3 视图一行，**4 视图默认 2×2**。调整方式：

- **拖动任意窗格的标题栏**（徽章 + 文件名区域）到另一窗格：
  - 落在目标**左/右 25%**：把源窗格插入目标格左/右（源窗格先从原行移出，目标行多一格）
  - 落在目标**上/下 25%**：在目标行上方/下方新开一整行，被拖窗格独占一行
  - 落在**中间 50%**，或直接落在目标的**标题栏**上：两个窗格交换位置
  - 目标窗格边缘亮起蓝色边框；窗格间隙里出现 4px 蓝色插入线（新行插入线横跨整行）＝即将插入的位置；释放鼠标生效，`Esc` 取消
- **右键标题栏**：`Reset layout` 恢复当前视图数的默认布局；下方预设（如 4 视图的 1×4 / 2×2 / 3+1 / 竖排）
- 拖动期间快捷键暂时禁用；**录屏中不能排列**（拖拽、右键预设与重置都会被拒绝，先停止录制）
- **视图身份不随位置变化**：A 始终是主时间轴，徽章字母、时间轴顺序和同步关系都跟着视图走，只换显示位置
- 自定义排列在增删视图时保留；未手动排列时按默认递进（2→3→4 为 1×2→1×3→2×2）
- 排列只在本次运行内有效（不写入设置，重启恢复默认）

## 视频块（每视图一套）

| 控件 | 作用 |
| :--- | :--- |
| `A`–`D` 徽章 | 块的标识，颜色见文首色板 |
| 文件名 | 当前加载的视频文件名 |
| 视频区 | 渲染画面。**滚轮**＝**所有视图联动**按档位缩放（各自在自己档位上前进/后退一档，保留倍率差）；**按住左键拖拽**＝**所有视图联动**平移（像素级 1:1 跟随鼠标，各自边缘钳制）；**双击**＝**所有视图联动**复位缩放、平移和旋转 |
| **Ctrl+滚轮** | 仅本侧缩放 |
| **Ctrl+左键拖拽** | 仅本侧平移（1:1 抓取，拖到边缘自动停住） |
| **Ctrl+双击** | 仅本侧复位缩放、平移和旋转 |
| `<` / `>`（块底部） | **本侧单独**逐帧后退/前进。用于把各画面定位到同一物理瞬间（如秒表跳到同一读数） |
| `Play` / `Pause`（块底部） | **本侧单独**播放/暂停——快速跳到同步点附近再配合 `<` `>` 微调；同步播放中按它会先全局暂停再单独控制该侧 |
| `↻ 90°`（Play 旁） | **本侧顺时针旋转 90°**（循环 0→90→180→270→0），旋转时平移自动回中、缩放保留，当前角度直接显示在按钮上 |
| `×2.4`（块底部） | 本侧当前缩放档位，琥珀色，始终显示（1x 显示 `×1.0`）。缩放/平移默认操作**所有视图**，Ctrl 修饰后仅操作**本侧** |
| 时间读数 | 该视频自己的时间轴位置（秒），等宽字体显示 |

## 主时间轴（共享传输栏上方）

多杆滑杆（每视图一杆，上＝A、下＝B、再下＝C/D），共享同一时间比例尺（满量程＝所有视频中较长的那个），因此播放时**所有白色旋钮移动速度严格一致**，各跟随杆与 A 杆的水平间隔恒等于各自的同步偏移：

- 各杆已播放段用**本视图徽章色**填充（A 蓝 / B 绿 / C 靛蓝 / D 橙）；灰色段＝该视频剩余部分；**暗色尾段＝超出该视频时长的死区**（直观显示时长差异）
- 顶部无字刻度线＝秒刻度（自适应间距）
- **黄色菱形**＝同步锚点：每根已同步的杆**各有一个**——A 杆的锚点在 point_a 处、各跟随杆在自己的 point 处，水平间距就是各自 offset，diff 一目了然；未同步的视图无锚点
- **点击或拖动任意一根杆**＝所有视图同步精确跳转（保持对齐）；拖动中做快速预览（按关键帧），**松手瞬间精确落点**
- 未加载的视图显示为整条死区轨道

## 共享传输栏（居中三组）

左组（文件与视图）：

| 控件 | 作用 |
| :--- | :--- |
| `Open A`–`Open D` | 弹文件对话框，为对应视图选择视频（也可直接拖文件进块）。按钮随视图数动态显示 |
| `＋` | 追加一个视图（上限 4，等同 `V` 键）；到上限后置灰 |
| `－` | 移除最后一个视图（最少保留 2 个）；2 视图时置灰 |

中组（走带控制）：

| 控件 | 作用 |
| :--- | :--- |
| `\|<` | 跳到公共播放区间的**第一帧**（所有已加载视频的公共区间；区间不重叠时不会跳转并给出提示） |
| `<` / `>` | **所有视图同步**逐帧后退/前进（步长以 A 的帧率为准） |
| `Play` / `Pause` | 同步播放/暂停；播到结尾后再按会回到开头重播 |
| `>\|` | 跳到对齐区间的**最后一帧** |

右组（速度与同步）：

| 控件 | 作用 |
| :--- | :--- |
| `speed` 下拉框 | 播放速度：0.1x / 0.25x / 0.5x / 1x / 2x / 4x，所有视图同时生效。**速度会记入设置，下次启动直接以该速度播放** |
| `⇄ Align current frames` | **一键同步**：把所有已加载视图的"当前帧"设为同步锚点（等同 `S` 键）。A 是主时间轴，每个跟随视图与 A 各建一对偏移 |
| `● not synced / +x.xxxs / 多偏移` | 同步状态指示：琥珀色＝未同步；1 对偏移显示 `● +x.xxxs`，多对显示 `● AB +x.xxx · AC −x.xxx`（绿色） |
| `Clear sync` | 清除所有同步点，时间轴恢复原始对齐（所有 offset = 0） |
| `⏺ Rec` | **录屏**开始/停止（等同 `F9`），见下节 |
| `✛` | **十字准星**开关（等同 `C`）：每个视图**窗格中心**各显示一条 **1px 红色十字线**（mpv OSD 渲染）。缩放/平移/旋转时十字**保持不动**——是屏幕参照物，正好用来对比各视图运动幅度；状态会记入设置，开启时也会被录进录屏 |

## 录屏（F9）

把**所有视频块**（含标题栏与本侧控制条，不含时间轴/走带栏/状态栏）录成 mp4，用于对齐后同步播放的对比展示：

- **`F9` 或 `⏺ Rec`** 开始：按钮变红并显示计时 `⏺ 0:12`；再按一次停止
- 停止后自动在资源管理器中定位到产物文件，保存位置：`视频\vcplayer\compare_年月日_时分秒.mp4`
- 编码按机器能力自动选档（启动时探测一次）：**桌面复制 + NVENC 硬编 60fps**（N 卡）→ **桌面复制 + x264 30fps**（任意显卡）→ **gdigrab + x264**（仅完整版 ffmpeg；远程桌面等 DDA 不可用场景）
- **主屏录制**所有配置可用；窗口在副屏时需要 gdigrab 档（打包版 ffmpeg 不含 gdigrab，会提示把窗口移回主屏）
- **录制期间不要移动/缩放窗口**（录的是屏幕区域），也不要增删视图、拖动排列窗格或让其他窗口遮挡视频区；鼠标指针会被录进去

## 同步用法（一步完成）

多个视频拍摄开始时间不同是正常情况，同步锚点就是为此设计的：

1. 用各块底部的 `Play` 单侧播放快速到达目标段，`<` `>` 逐帧把**每个视图**走到**同一物理瞬间**——比如秒表刚跳到 `05.00` 的那一帧（选数字跳变帧，别选读数静止的中间帧）
2. 点 **`⇄ Align current frames`**（或按 `S`）
3. 完成：状态 chip 变绿显示各对偏移，每根已同步的杆出现一个黄色菱形锚点，之后所有播放/逐帧/拖动都按对齐时间走。**未加载视频的视图不参与对齐**（如 C 空载时只对齐 A–B，之后给 C 加载视频再按一次 `S` 补对齐即可）

同步后再按 `Space` 同步播放时，某视图偏差超过约一帧（如手动步进过它）会先精确吸附到 A 当前对齐位置再起播；偏差在一帧内则直接起播，由各对独立的速度微调环收敛残余偏差（避免无谓的 seek 卡顿）。

两台设备帧率不同时（如 120fps vs 30fps），以高帧率侧的跳变帧为准，低帧率侧选"刚跳到新读数的第一帧"，残余误差最多一帧。**某视图换视频后，与它相关的同步自动清除**（换 A 则全部清除），需重新对齐。

## 状态栏（窗口最底部）

1–2 对偏移时逐对显示；3 对（4 视图全部同步）时一行放不下，简化为汇总，**鼠标悬停看明细**：

```
A 12.345s | offset +0.040s | drift +0.0ms | 120fps                     （2 视图）
A 12.345s | AB +0.040s (+0.0ms) | AC −0.120s (+1.2ms) | 60fps          （3 视图）
A 12.345s | 3 synced pairs | max drift +1.2ms | 60fps                   （4 视图，悬停看明细）
```

| 字段 | 含义 |
| :--- | :--- |
| `A ...s` | 主时间轴当前位置（即 A 的时间） |
| `offset` / `AB` / `AC` … | 同步偏移量：该跟随视图相对 A 的时间差（每对独立） |
| `drift` | 播放中各对的实时偏差。播放时通过**微调各跟随侧的播放速度（±10% 内）**连续收敛，启动瞬间约几十毫秒的管线唤醒差会在 ~1 秒内平滑归零；暂停时自动吸附到 ≤1 帧 |
| `fps` | 参考帧率（A 视频的帧率，也是逐帧步进的步长基准） |

## 快捷键

| 键 | 功能 |
| :--- | :--- |
| `Space` | 同步播放/暂停 |
| `←` / `→` | 所有视图同步逐帧后退/前进 |
| `↑` / `↓` | 变速（在速度档位间循环） |
| `Home` / `End` | 跳到对齐区间开头/结尾 |
| `S` | **一键对齐当前帧**（等同 `⇄ Align current frames`） |
| `R` | 清除所有同步（等同 `Clear sync`） |
| `F9` | **录屏**开始/停止（等同 `⏺ Rec`） |
| `C` | **十字准星**开关（等同 `✛`） |
| `V` | **追加一个视图**（等同 `＋`，上限 4；移除用 `－` 按钮） |
| `Ctrl+O` | 为当前块打开视频文件 |
